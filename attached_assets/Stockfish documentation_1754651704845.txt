# Minimal command flow (UCI)

Typical conversation with the engine:

```
uci
isready
ucinewgame
position fen <FEN>   # or: position startpos moves e2e4 e7e5 ...
go depth 15          # or: go movetime 1000  / go nodes 2000000  / go infinite
stop                  # only for go infinite
quit
```

Stockfish replies with lines like `id name Stockfish`, `option name Hash …`, `uciok`, `readyok`, periodic `info …` lines, and finally `bestmove <move> [ponder <move>]`. (Command meanings and replies are detailed in the official “UCI & Commands.”) ([official-stockfish.github.io][1])

# Tiny, working examples

## Python (no dependencies, just `subprocess`)

```python
import subprocess, sys, time

sf = subprocess.Popen(
    [r"C:\path\to\stockfish.exe"],  # or "/usr/bin/stockfish"
    stdin=subprocess.PIPE,
    stdout=subprocess.PIPE,
    universal_newlines=True,
    bufsize=1
)

def send(cmd):
    sf.stdin.write(cmd + "\n")
    sf.stdin.flush()

def read_until(tokens=("uciok","readyok","bestmove")):
    for line in sf.stdout:
        # print(line.strip())  # uncomment to debug
        if any(line.startswith(t) for t in tokens):
            return line.strip()

send("uci")
read_until(("uciok",))
send("setoption name Hash value 1024")
send("setoption name Threads value 8")
send("isready")
read_until(("readyok",))

send("ucinewgame")
send("position fen rnbqkb1r/ppp2ppp/8/4P3/8/2pP1N2/P1P3PP/R1BQKB1R w KQkq - 0 8")
send("go depth 20")
best = read_until(("bestmove",))
print(best)

send("quit")
sf.wait()
```

## Python (with `python-chess` engine helper)

```python
import chess
import chess.engine

engine = chess.engine.SimpleEngine.popen_uci(r"C:\path\to\stockfish.exe")
engine.configure({"Hash": 1024, "Threads": 8, "MultiPV": 3})  # option names are from Stockfish UCI Options
board = chess.Board("rnbqkb1r/ppp2ppp/8/4P3/8/2pP1N2/P1P3PP/R1BQKB1R w KQkq - 0 8")
info = engine.analyse(board, chess.engine.Limit(depth=20), multipv=3)
for i, pv in enumerate(info, 1):
    print(i, pv["score"], pv["pv"])
engine.quit()
```

(`python-chess` wraps UCI for you, but the option names/values still come from Stockfish’s UCI options.) ([Stockfish][2], [official-stockfish.github.io][5])

## Node.js (child\_process)

```js
const { spawn } = require("child_process");
const sf = spawn("stockfish"); // ensure it's on PATH or give full path

sf.stdout.setEncoding("utf8");
sf.stdout.on("data", data => {
  data.split(/\r?\n/).forEach(line => {
    if (line) console.log("SF:", line);
  });
});

function send(cmd){ sf.stdin.write(cmd + "\n"); }

send("uci");
send("setoption name Hash value 256");
send("isready");
send("ucinewgame");
send("position startpos moves e2e4 e7e5 g1f3 b8c6");
send("go movetime 1000");
setTimeout(() => send("quit"), 2000);
```

# Commonly used UCI options (Stockfish)

* `Hash` (MB of transposition table), `Threads`, `MultiPV` (number of lines), `Move Overhead`, `UCI_LimitStrength`/`UCI_Elo`, `SyzygyPath`, `Use NNUE`, etc. Full, up-to-date list is in Stockfish’s UCI Options page; option names must match exactly. ([Stockfish][2])

# Sanity tips

* Always send `uci` first and wait for `uciok`. Then `isready` → `readyok` after changing options or positions. This keeps your I/O synced. ([official-stockfish.github.io][1])
* For repeated analyses, send `ucinewgame` when you start a fresh session or change context significantly (it clears state). ([GitHub][4])
* If you want multiple best lines, set `MultiPV` and parse multiple `info` lines with different `multipv` indexes before the final `bestmove`. ([Stockfish][2])
